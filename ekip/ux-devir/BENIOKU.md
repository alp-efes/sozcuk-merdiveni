# UX devir notu (geçici, birleştirilmez)

Tasarım takımının (Fable 5.2) yarıda kalan çalışması; CEO oturumu değişirken
kaybolmasın diye burada. Yeni CEO bunu UX işinin başlangıç noktası olarak
kullanır, iş bitince bu klasör silinir.

- `maket/`: iPhone boyutunda maketler (açılış, ana ekran, ilk oyun yardımı,
  yerel klavye açık oyun, yazarken, geçersiz kelime, ipucu, serbest oyun,
  kazanma, çözülmüş günlük, yardım).
- `prototip/`: uygulama kipindeki prototipin web dosyaları (iOS `www/`
  kopyası). Yeni olanlar `uygulama.js` ve `uygulama.css`; diğerleri
  prototip sırasında değiştirilmiş kopyalar, depodaki asıllarıyla
  karşılaştırılarak okunmalı. Test edilmedi, denetimden geçmedi.

Sahibin istekleri (13 Kasım 2026, TestFlight sonrası), yalnızca UYGULAMA için
(web bugünkü gibi kalacak):
1. Kendi ekran klavyemiz yok, telefonun klavyesi; ekran klavyeyle kaymasın.
2. Açılış ekranı + ana ekran (Günün Bulmacası / Serbest Oyun).
3. Genel UX iyileştirmesi araştırması; UX işinde Fable 5.2 kullanılacak.
